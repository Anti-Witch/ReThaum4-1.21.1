# Thaumcraft 4 Reforged

Порт **Thaumcraft 4** (Minecraft 1.7.10) на **Minecraft 1.21.1 / NeoForge**.

Все робимо 1:1 з оригіналом: механіки, текстури, моделі беремо з декомпільованого TC4
(лежить поруч у `OpenTC4-master`), а не вигадуємо. Якщо сумнівно — ліземо в код і робимо як там.

---

## Стан: рання альфа

Гру можна проходити: дослідження → жезли → алхімія → інфузія. Але частина систем
ще недороблена — дивись список нижче, перш ніж писати про баги.

### Що вже працює

**Основа**
- Аура vis/flux по вимірах, вузли з випадковими типами, модифікаторами й аспектами.
- Таумометр: 3D-модель у руці, сканування предметів, бачить вузли крізь стіни.
- Таумономікон: усі **201 дослідження** TC4 у 6 категоріях (Основи, Тауматургія, Алхімія,
  Мистецтво, Големантія, Ельдрітч), 310 сторінок з текстом і рецептами.
  Дається ПКМ жезлом по книжковій полиці.
- Стіл досліджень, теоркрафт, warp.

**Жезли**
- Збірка на аркан-верстаку (стрижень + 2 наконечники), скіпетри (+50% ємності, −0.1 витрат).
- Усі стрижні/наконечники/посохи з TC4. 3D-жезл у руці, 2D-іконки стрижнів і наконечників.
- Заряджання vis від вузлів (затиснути ПКМ на вузлі), гейти досліджень NODETAPPER/NODEPRESERVE.
- Фокуси: вогонь / блискавка / копання — снаряди літають, vis списується.
- HUD жезла: золоте коло з капсулами аспектів, стрілки приросту/витрати, фокус у центрі.

**Алхімія**
- Тигель (нагрів, розчинення, 49 рецептів), алхімічна печі, алембіки, труби, банки,
  резервуар есенції, центрифуга.
- Протікання: переповнений тигель залишає flux goo/gas, які розповзаються й тейнять землю.

**Інфузія**
- Рунічна матриця: активується жезлом, перевіряє структуру (4 стовпи + п'єдестали),
  анімації, потоки частинок від п'єдесталів, нестабільність, **63 рецепти**.

**Різне**
- Аспект-орби: випадають з мобів (50% на примал), летять до жезла в хотбарі й заряджають його.
- Ярлики: фільтри на банки, труби й алембіки (ПКМ — повісити, Shift+ПКМ — зняти).
- Стіл розщеплення: розкладає предмети на аспекти в пул гравця.
- Големи (частково), броня (окуляри одкровення, чоботи мандрівника, fortress/void/cultist),
  тейнт, аркан-пристрої, дзеркала, лампи, банки, мозок у банці.

### Що ще не зроблено

- Hover Harness не літає (зареєстрований як звичайний бабл).
- Вузол у банці (Node in a Jar) — заглушка: при поставці вузол губиться.
- Fortress: сет-бонус не працює, немає інфузійних рецептів для окулярів-шолома й масок.
- Частинки фокусів: снаряди без трейлу й ефекту влучання.
- Зачарування через інфузію (InfusionEnchantmentRecipe) і NBT-виводи.
- Голем-апгрейди й печатки (seal-система) не підключені.
- ~126 сторінок досліджень посилаються на рецепти, яких у порті ще немає
  (Focal Manipulator, чисті метали, маски тощо).
- 3D-моделі броні fortress/cultist/praetor — поки заглушки.

## Як зібрати

Потрібен **JDK 21**.

```bash
./gradlew build        # jar з'явиться в build/libs/
./gradlew runClient    # запустити клієнт для тестів
```

Готовий jar кидаєш у `mods/` на NeoForge 1.21.1. Додаткових залежностей не треба
(Curios вбудований всередину).

A community port of **Thaumcraft 4** (1.7.10) to **Minecraft 1.21.1 / NeoForge**.
Behaviour, assets and mechanics are recreated 1:1 from the original TC4 source

**Early alpha**: the full loop (research → wands → alchemy → infusion) is playable.
Not done yet: Hover Harness, Node in a Jar, Fortress set bonus + mask recipes,
focus projectile FX, infusion enchantments, golem upgrades/seals, ~126 research
pages whose recipes aren't ported yet, armour gear models.

Build with JDK 21: `./gradlew build`. Drop the jar into `mods/` on NeoForge 1.21.1.
